CSC110/111 VS Code course folder

This folder is the starting folder for your CSC110 or CSC111 work.

After extracting the zip file:

1. Open Visual Studio Code.
2. Import csc110-vscode.code-profile using:
   File > Preferences > Profiles > Import Profile...
3. Open this csc110 folder using:
   File > Open Folder...
4. If VS Code asks whether you trust the folder, choose:
   Yes, I trust the authors.
5. Open the VS Code terminal and install the course libraries:

   Windows:
   python -m pip install -r requirements.txt

   macOS:
   python3 -m pip install -r requirements.txt

6. Open welcome.py and run it.
